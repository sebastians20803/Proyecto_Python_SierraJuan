# 💰 Simulador de Gasto Diario

Aplicación desarrollada en **Python** como proyecto de aprendizaje, enfocada en la aplicación de conceptos fundamentales de programación, manejo de datos y lógica para registrar y analizar gastos diarios.

El proyecto permite simular la gestión de gastos personales y obtener información sobre el dinero utilizado durante un período determinado.

---

## 🎯 Objetivo

El objetivo del proyecto es poner en práctica conceptos fundamentales de programación mediante el desarrollo de una aplicación para la gestión de gastos.

A través del proyecto se trabajan conceptos como:

- Variables y tipos de datos.
- Condicionales.
- Ciclos.
- Funciones.
- Listas y estructuras de datos.
- Entrada y salida de información.
- Operaciones matemáticas.
- Lógica de programación.

---

## ⚙️ Funcionamiento

El usuario puede ingresar información relacionada con sus gastos diarios y el programa procesa los datos para llevar un control del dinero utilizado.

El flujo general del programa es:

```text
             👤 Usuario
                 │
                 ▼
        Registrar información
                 │
                 ▼
          💵 Gastos diarios
                 │
                 ▼
        ┌─────────────────┐
        │ Procesamiento   │
        │ de los datos    │
        └────────┬────────┘
                 │
                 ▼
        📊 Resultados
```
